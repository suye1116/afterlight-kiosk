# 기존 프로젝트 분석 — AFTERLIGHT (개인 우주 버전)

조사 대상
- 배포본: https://suye1116.github.io/afterlight/
- 원본 소스: https://github.com/suye1116/afterlight (공개, `main` 브랜치, 커밋 2개)
- 읽기 전용으로 임시 폴더에 복제해 확인했다. **기존 저장소에는 아무것도 쓰지 않았다.**

기술 스택: React 19 + TypeScript + Vite 8, zustand, framer-motion.
저장소는 브라우저 `localStorage` 하나뿐(`afterlight.sky.v2`). 서버·외부 API·키 없음.

## 1. 화면 구성과 이동 흐름

페이지를 옮기지 않는다. **같은 하늘(캔버스) 위에서 장면만 겹쳐 바뀐다.**

```
intro ──▶ compose(1→2→3) ──▶ arriving ──▶ mytime
  │                                          │
  └── 상단 내비 ── MY TIME / ALL LIGHTS / ABOUT ─┘
```

| 장면 키 | 이름 | 하는 일 |
| --- | --- | --- |
| `intro` | 인트로 | 어두운 우주에 문장이 빛처럼 하나씩 도착. 내비게이션 없음 |
| `compose` | 세 걸음 | 1 적는다 → 2 고른다 → 3 보낸다 |
| `arriving` | 도착 | 먼 곳의 점 하나가 하늘의 제자리로 내려앉는다 |
| `mytime` | MY TIME | 내 우주. 별 선택 · NOW/THEN · 잔광 보기 · 시간이 쌓인 순서 · 다시 도착한 빛 |
| `alllights` | ALL LIGHTS | 책(도감) 형식. 펼침면 2쪽, 쪽당 3개. 분류 4개 |
| `about` | ABOUT | 작품 의도 + 여덟 기능 안내 |
| `ouruniverse` | OUR UNIVERSE | **꺼져 있음**(`features.ts`의 `OUR_UNIVERSE_ENABLED = false`) |

상단 내비게이션은 네 개뿐이다 — `AFTERLIGHT` / `MY TIME` / `ALL LIGHTS` / `ABOUT`.
`intro`와 `arriving`에서는 내비게이션을 띄우지 않는다.

### 화면의 네 겹 (`global.css`)

```
z 0  .layer--sky     캔버스 — 성운 · 배경별 · 기억별 · 별자리 선   (pointer-events: none)
z 1  .layer--veil    장막 — 중심을 어긋낸 비네팅 + 따뜻한 얼룩 셋
z 2  .layer--grain   필름 입자 — SVG feTurbulence, 이미지 파일 아님
z 3  .layer--stage   무대 — 글자. 입자보다 위라 가독성을 잃지 않는다
```

별을 누르는 판정은 캔버스가 아니라 엔진이 `window` 좌표로 직접 한다.

## 2. 색 · 폰트 · 배경 · 별 · 애니메이션 · 여백

### 색 토큰 (`src/styles/tokens.css` 원문 값)

```
밤      --ink-900 #04050b   --ink-800 #06070e (기본 배경)
        --ink-700 #090911   --ink-600 #0d0c15
빛      --light-100 #f7f0e3  --light-200 #d9d0c0
        --light-300 #9d9484  --light-400 #6a6257
도착한 빛 --cream #fff8e9  --amber-200 #f7dcb0  --amber-300 #efc188
        --amber-400 #d3945a  --apricot #e8a98c  --ember #b96b56
그림자  --violet-shadow #3c3a68   --blue-shadow #2b3358
선      --line rgba(214,198,176,.2)   --line-strong rgba(240,226,203,.42)
```

색의 원칙(주석 원문): *배경은 검정이되 평면이 아니고, 빛은 차갑지 않다. 푸른빛은 주인공이 아니라 그림자에 극소량 섞이는 불순물이다.*
순수한 `#000`은 한 곳도 없다.

### 폰트

```
--font-display: 'Jost', 'Noto Sans KR', 'Apple SD Gothic Neo', sans-serif
--font-korean : 'Noto Sans KR', 'Apple SD Gothic Neo', sans-serif
```
Google Fonts에서 `Jost:200,300,400` + `Noto Sans KR:200,300,400`만 받는다.
본문 16px / line-height 1.9 / letter-spacing .01em.
작은 글자 토큰: `--text-micro .66rem`, `--text-tiny .72rem`, `--text-small .8rem`
(720px 이하에서만 .78 / .82 / .88rem로 올린다 — 색은 그대로 둔다).

### 배경 (성운 · 입자)

- 성운은 이미지가 아니라 `canvas/nebula.ts`가 fBm 잡음 다섯 장으로 픽셀을 계산한다.
  러스트(134,52,26) → 앰버(214,124,54) 사이를 오가고, 그림자에만 청보라를 `0.2 * (1-d)`만큼.
  가장 두꺼운 곳에만 살구빛(236,178,130)이 올라온다. 전체 세기 계수 `k = d * 0.42`.
- 성운 위의 큰 결 세 곳은 중심을 피해 `(.19,.73) (.76,.25) (.54,.90)`에 둔다.
- 필름 입자: `--grain-opacity .22`, `--grain-size 170px`. 720px 이하 `.2 / 120px`, 2dppx 이상 `.19`.

### 별 그래픽

**배경 별** (`canvas/stars.ts`) — 네 종류, 비율이 정해져 있다.

```
point 63%  soft 22%  bloom 9%  spike 6%
```

색 비율(이 비율이 무너지면 곧바로 SF 우주가 된다 — 주석 원문):

```
#fffdf7 흰빛 28 · #fff3dd 크림 24 · #ffe3b8 금빛 17 · #f8c98f 앰버 13
#eeab7d 옅은 주황 8 · #dd9184 살구·붉은빛 4 · #c6cfee 청보라 6
```

숨 쉬는 별은 26%뿐, 주기 35~130초.

**기억 별의 생김새** (`canvas/memoryForms.ts`) — 씨앗 하나가 결정, 저장하지 않는다.

```
ember 34%  (core .88 halo .54 haloAlpha .52 spike 0)
cross 24%  (core .78 halo .68 haloAlpha .46 spike .50 reach 1.18)
halo  22%  (core .58 halo .98 haloAlpha 1.0  spike 0)
soft  20%  (core .70 halo 1.52 haloAlpha .82 spike 0)
```
여기에 ±12% 흔들림과 별 자체 크기 `magnitude 0.82~1.30`이 곱해진다.

**별자리 선** (`canvas/starfieldEngine.ts`)

```
LINK_RADIUS 0.34 (짧은 변 대비)   한 별이 잇는 선 최대 2개(DEFAULT_LINK_MAX)
LINK_INK #f0e6d2   LINK_BASE .42  LINK_HOVER .70  LINK_PICKED .82  LINK_NEAR .12
LINK_WIDTH 1.1px (좁은 화면 1.35)  글로우 3.2px / alpha .17 (blur 안 씀)
LINK_CLEAR 1.7 (핵 반지름 배수) + 3px — 선이 별을 꿰뚫지 않는다
LINK_REVEAL_MS 1800 — 선이 그어지지 않고 배어 나온다
```
좁은 화면(<640px)과 OUR UNIVERSE에서는 `linkMax = 1`.

### 애니메이션 리듬

```
--ease-out-soft cubic-bezier(.16, 1, .3, 1)
--dur-slow 2400ms (빛이 도착하는 속도)  --dur-mid 1200ms  --dur-fast 480ms
```
장면별 하늘 물러남(`DIM_BY_SCENE`): intro 0 · compose .62 · arriving .42 · mytime 0 · alllights 0 · about .42

주요 박자
```
인트로 문장 beats  1000 / 1700 / 2900 / 4300 / 5400 ms (6.8초면 전부 읽힘)
도착     landing 2600ms → settle 1400ms, 문장 fadeIn 900 / hold 2000 / fadeOut 1200
첫 기억  beats 0 / 1300, fadeOut 3000, end 3900
다시 도착한 빛  대기 300~700ms, 빛의 여정 2.8초, 답 남긴 뒤 1600ms
시간이 쌓인 순서  시작 문장 1500ms, 별 간격 1.75/1.3/1.0초(개수별), 끝 문장 2600ms
흘려보낸 빛이 옅어지는 시간 LETGO_FADE_MS 25,000ms → 잔광 0.12
```

### 여백과 레이아웃

```
--gutter clamp(20px, 5vw, 64px)
--stage-pad-y clamp(32px, 7vh, 88px)   (높이 520px 이하에서는 18px)
--measure 34rem                         (한 줄이 숨 쉬는 너비)
--nav-height 64px (620px 이하 68px)
--safe-top/right/bottom/left = env(safe-area-inset-*)
```
별의 저장 좌표 범위 `FIELD = {left .06, right .94, top .10, bottom .88}`,
그릴 때 `canvas/safeArea.ts`의 `toSafe()`가 화면 안전 영역으로 다시 매핑한다.
글자가 놓인 자리는 `[data-safe]`로 하늘에 알려 주고, 엔진이 `clip('evenodd')`로 그 자리를 파내 선을 긋지 않는다.

금지된 미감(원문): *게임 UI · SF HUD · 사이버펑크 · 과한 네온 · 그라디언트 버튼 · SaaS 카드 그리드 · 과한 글래스모피즘 · 평범한 일기앱 UI · 흰 문서 페이지 · 대시보드 · 댓글/채팅 목록.*
*이 작품의 화면에는 머리띠도, 상자도, 테두리도 없다.*

## 4. 시간 기록과 관련된 입력 항목

현재 사용자가 입력하는 것은 **단 두 가지**다.

| 항목 | 형태 | 제한 | placeholder |
| --- | --- | --- | --- |
| 기억의 한 문장 | `<input type="text">` 한 줄 | `TEXT_LIMIT = 80`자, 입력 중 `{n} / 80` 표시 | `친구들과 처음 여행 갔던 날` |
| 다시 도착한 빛에 남기는 반응 | 텍스트 | — | `그땐 몰랐는데, 지금 생각하면 참 소중했던 것 같다.` |

**날짜·시각을 직접 입력하는 칸은 없다.** `createdAt`은 보낸 순간이 자동으로 들어가고,
그 의미는 '저장한 때'가 아니라 **'빛이 현재에 닿은 때'**다(`types/index.ts` 주석).
엔터가 곧 다음 걸음이며, 비어 있으면 다음 버튼이 꺼져 있다.
날짜 계산은 반드시 `calendarDaysAgo()`(자정 기준)를 쓴다 — 밀리초를 86400000으로 나누면 어젯밤 11시 기억이 '오늘'로 읽힌다.

## 7. 별과 별자리 관련 기능

- **배치** (`lib/starMath.ts`) — 균일 난수를 쓰지 않는다. 새 빛은 70% 확률로 이미 있는 빛 곁에 앉고(군집), 나머지는 아무도 없는 곳에 새 자리를 연다.
  ```
  CLUSTER_CHANCE .70 (빛이 8개 미만이면 .40)
  CLUSTER_NEAR .042 ~ CLUSTER_FAR .115   NEW_REGION_GAP .22
  MIN_SEPARATION .032   CLUSTER_CAP 6   NEIGHBOUR_RANGE .13   X_SQUEEZE .62
  ```
  은하수 띠(`lib/noise.ts`의 `bandWeight`)를 따라 더 자주 앉는다.
- **별자리 선** — 가까운 것끼리, 한 별에 최대 2개. 전부 이으면 그물이 된다.
  선은 캔버스(z0)에 그려지므로 글자 위로 올라오지 않고, `[data-safe]` 자리는 파낸다.
- **기억의 중력** — 간직한 별에 다가가면 둘레 공간이 미세하게 휜다(`GRAVITY_REACH .2 / FIELD .3 / PULL 2.4`). 커서를 끌어당기지는 않는다.
- **NOW / THEN** — 슬라이더로 시점을 고르면 그 이후의 별이 역순으로 빛을 잃고 먼 우주로 돌아간다.
- **시간이 쌓인 순서** — 오래된 별부터 하나씩 도착하며 별자리를 다시 짓는다(전체 12초 이내).
- **다시 도착한 빛** — 누르는 기능이 아니다. 하늘을 보고 있으면 3일(`RETURN_MIN_DAYS`)이 지난 별 하나가 스스로 다시 도착한다. 별을 새로 만들지 않고 `returning.ts`가 별도 기록(visits + reaction)으로만 남긴다.
- **잔광 보기** — 필터가 아니라 눈이 어둠에 익는 일. 두 톤의 밝기·크기·색이 서로 반대 방향으로 움직인다.
