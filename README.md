# AFTERLIGHT · 아직 도착 중인 시간
### 전시 키오스크 / 공동 우주

> 우리가 밤하늘에서 보는 별빛은 그 별의 현재가 아니라,
> 오래전에 출발한 과거의 빛이다.

원작(개인의 우주)은 한 사람의 하늘이었다. 이 버전은 **전시를 다녀간 모든 사람의 하늘**이다.
관람객은 태블릿에서 시간을 기록하고, 감정을 고르고, 간직할지 흘려보낼지 정한다.
보낸 빛은 공동 우주로 건너가 **같은 감정의 빛끼리 모여 별자리**가 된다.

두 곳을 **읽기 전용으로만** 참고했다. 어느 쪽도 수정하지 않았다.

```
github.com/suye1116/afterlight          공개 저장소 (커밋 e99fa21)
~/Desktop/조형실습/AFTERLIGHT            실제 작업본 — 공개본보다 앞서 있다
```

감정 일곱과 그 색은 **작업본의 `src/constants/emotions.ts`에서 그대로** 가져왔다.
무엇을 어떻게 이어받았는지는 [`src/INHERITED.md`](src/INHERITED.md)에 적어 두었다.

### 테스트 모드

혼자서는 별자리를 볼 수 없다. 공동 우주는 여러 사람이 모여야 비로소 별자리가 되기 때문이다.
그래서 왼쪽 아래에 **가짜 관람객을 한꺼번에 보내는 패널**을 둔다.

- `npm run dev`에서는 **언제나 보인다**
- 구운 결과(`npm run preview`, 배포본)에서는 주소에 **`?test=1`**을 붙였을 때만 보인다
  (`http://localhost:4173/?test=1`)

전시 빌드의 평소 화면에는 나오지 않는다.

### 전체화면

대기 화면을 누르는 **그 첫 손짓**에서 전체화면을 요청한다
(브라우저는 사용자 손짓에서 비롯된 요청만 받는다). 막히더라도 작품은 그대로 작동한다.

## 체험의 흐름

```
ATTRACT ──(화면 터치)──▶ INTRO ──▶ RECORD ──▶ EMOTION ──▶ CHOICE ──▶ CONFIRM
                                                                        │
                                                      SENDING ◀─────────┘
                                                         │
                                        DONE ·  arrived ─┘
                                                   │ 4.6초 뒤
                                                invite ──── 예 ──▶ UNIVERSE
                                                   │
                                                 아니요
                                                   │
                                                stayed ──▶ 영수증 · 또 하나 · 처음으로
                                                   │
          ATTRACT ◀──(무입력: 묻는 중 60초 / 그 밖 20초)──┘
```

| 장면 | 하는 일 |
| --- | --- |
| `attract` | 지금까지 모인 빛이 떠 있는 대기 화면. 어디를 눌러도 시작된다 |
| `intro` | 원작의 인트로 문장과 박자 그대로 |
| `record` | `지금 떠오르는 시간이 있나요?` + 한 문장(80자) + `그 시간은 언제였나요?`(선택) |
| `emotion` | **오늘의 마음 일곱** 중 하나. 고르는 일이 곧 다음 걸음이다 |
| `choice` | 간직하고 싶은 시간 / 흘려보내고 싶은 시간 |
| `confirm` | 무엇을 보내는지 눈으로 보고 손을 가까이 — **HC-SR04 손 감지 센서**로 보낸다(아래) |
| `sending` | 빛이 멀어지며 공동 우주로 건너간다 (2.6초, 아두이노 LED 다섯과 같은 시계) |
| `done` | 도착. 같은 감정의 빛이 몇 개인지. 영수증 미리보기 |
| `done` · 초대 | 완료 문장이 머문 뒤, **남의 별들을 만나 보겠냐고 묻는다.** 묻기만 하고 밀지 않는다 |
| `universe` | 모두의 빛과 감정별 별자리. 별자리 이름은 켜고 끌 수 있다 |

### 손을 가까이 가져가면 보낸다

`confirm` 화면에서는 버튼을 누르지 않는다. **HC-SR04 손 감지 센서** 위에
손을 가까이(약 15cm 안) 가져가 **1초쯤 유지**하면 그 순간 빛이 떠난다.

```
기본        "당신의 시간을 우주로 보낼까요?" + "센서 위에 손을 가까이 가져가 주세요."
손 감지     "당신의 빛이 깨어나고 있어요." — 가까워질수록 화면의 빛이 부드럽게 밝아진다
전송 중     "당신의 시간이 우주로 향하고 있어요." — 아두이노 LED 다섯이 같은 시계로 켜진다
전송 완료   "당신의 별이 우주에 도착했어요." — LED가 다 켜지고 벽(TD)이 확인한 뒤
```

- **"가깝다"의 판정, 1초 보유, 손을 떼야 다음 전송이 열리는지** — 전부
  하늘이 정한다(`src/lib/sensorGate.ts`). 아두이노와 다리는 거리값만 나른다
- **이 화면(`confirm`)에 있을 때만** 센서 신호가 전송으로 이어진다. 다른
  장면에서 손이 지나가도 아무 일도 일어나지 않는다
- 센서 신호가 끊기면 화면이 그렇게 말한다. 다리가 없어도, 장비가 없어도
  작품은 멈추지 않는다 — 다만 그때는 보낼 길이 없다는 뜻이다
- **개발 중에만** 보이는 보조 버튼(`npm run dev` 또는 `?test=1`)과 센서
  시뮬레이션 패널(왼쪽 위)이 있다. 전시 빌드에는 둘 다 나오지 않는다
- 자세한 다리·펌웨어 규약은 [`server/README.md`](server/README.md)의
  "장치 사이드채널" · [`server/firmware/`](server/firmware/afterlight_sensor)

### 보내고 난 뒤의 초대

별을 보낸 직후, 완료 문장이 머물 만큼 머문 뒤(4.6초)에 묻는다.

```
당신의 별이 우리의 우주에 도착했습니다.
이곳에는 당신처럼 시간을 보내온 수많은 별들이 있습니다.
그 별들의 이야기도 만나 보시겠어요?

      예, 우리의 우주를 볼래요      아니요, 이대로 머물게요
```

- **스스로 건너가는 일은 없다.** 고르지 않으면 그대로 머문다
- 두 길은 같은 무게다 — 보지 않겠다는 것도 하나의 답이다
- **아니요를 고른 사람에게 다시 묻지 않는다.** 완료 화면이 그대로 남는다
  (영수증 · 또 하나 보내기 · 처음으로)
- 묻는 동안에는 **60초**를 기다린다. 세 문단을 읽고 고를 시간이다
- 물리 버튼 하나로는 '아니요'를 고를 수 없다 — 만지지 않으면 그것이 답이 된다

### 열 개를 하나씩 들여다보기

우리의 우주에 들어서면 **실제로 모인 별 가운데 열 개**를 무작위로 골라
화면에 흩어 놓고, 하나씩 가운데로 불러 그 시간을 들여다본다.

**스스로 넘어간다.** 누르지 않아도 열 개가 차례로 지나간다 —
누군가는 서서 바라보기만 하고, 그래도 되어야 한다.

```
흩어진 열 개 (2.6초)
   ↓
① 다가옴   별이 가운데로 (1.6초) — 커지고 밝아진다
   ↓        나머지 아홉은 0.26까지 물러난다. 사라지지는 않는다
② 자리잡음 멈추고 한 숨 (0.3초)
   ↓
③ 떠오름   그 사람의 시간이 배어 나온다 (1.1초)
   ↓
④ 읽음     5.0~6.2초 — **글이 길수록 오래 머문다**
   ↓
다음 별이 같은 길을 간다 … 열 번째까지
   ↓
모두 만나 보았습니다 — 다시 보기 / 그만 보기
```

네 토막은 **겹치지 않고 차례로** 지나간다. 겹치면 무엇을 보아야 할지 알 수 없다.
**한 별에 8초**(글이 길면 9.2초까지), 열 개를 다 보는 데 1분 20초쯤.

보는 도중에도 **다음 별**로 먼저 갈 수 있고(누르면 시계가 거기서 다시 걸린다),
**감상 종료**로 언제든 처음으로 돌아갈 수 있다.

> **박자를 고치는 곳은 `src/lib/showcase.ts`의 `VIEWING` 하나다.**
> 한 별에 걸리기를 바라는 시간은 같은 파일의 `STEP_TARGET_MS`(8초)이고,
> 읽는 시간은 `holdFor()`가 글자 수에 따라 정한다.

- **없는 별을 지어내지 않는다.** 열보다 적으면 있는 만큼만, 없으면 빈 채로 둔다
- 같은 별이 두 번 뽑히지 않는다 (300벌을 뽑아 확인)
- 흩어진 자리는 별의 이름에서 나온다 — 같은 별은 언제 보아도 같은 자리
- 뒤의 하늘(성운 · 배경별 · 다른 사람들의 빛)은 **그대로 돈다**

### 남의 이야기는 동의한 것만

별에 `shared`라는 칸이 있고, **적혀 있을 때에만** 동의한 것으로 본다.
지금은 동의를 묻는 걸음이 없으므로 **남이 적은 글은 한 줄도 뜨지 않는다** —
숨긴 것이 아니라 묻지 않았기 때문이고, 화면도 그렇게 말한다
(`이 시간의 내용은 공개되지 않았습니다`).

| | 보이는 것 |
| --- | --- |
| 남의 별 (동의 없음) | 마음 · 간직/흘려보내기 · 언제의 시간인지 · 번호 — **넷 다 고른 항목이다** |
| 남의 별 (동의함) | 위 + 남긴 한 문장 |
| 자기 별 | 위 + 자기가 적은 문장 (`당신이 보낸 빛입니다`) |

이름도 연락처도 **애초에 묻지 않으므로** 담길 자리가 없다.
규칙은 `src/lib/showcase.ts`의 `contentOf()`와 `src/lib/stories.ts` 두 곳뿐이다.

### 감정별 색 — 2026-10-16에 벌렸다

원작은 "핵은 크림빛 고정, 마음의 색은 번짐에만 0.34"였다. 나란히 두면
'같은 하늘의 다른 온도'로 읽히지만, **네 면에 투사해 멀리서 보면 일곱이
거의 같은 빛**이 된다. 그래서 색상환에서 벌렸다.

```
         원작(tint)   →   지금(외곽광)
가장 가까운 두 색  24.6   →   61.0
```

세 겹(중심광 · 외곽광 · 잔광)이 모두 그 마음의 색을 진다.
형광으로 가지 않게 외곽광·잔광의 가장 밝은 칸은 235를 넘지 않고,
진하기는 0.65를 넘지 않는다. **'기타'에는 색을 주지 않았다** —
이름 붙이지 않은 마음에는 색도 없다.

원작의 색은 `tint`로 **그대로 남아 있다**. 되돌릴 일이 생기면 그 자리다.
색은 전부 `src/constants/emotions.ts` 한 곳에 있다.

## 전시 장비와의 다리

```
웹사이트 ──ws──▶ server/index.js ──ws──▶ TouchDesigner (네 면)
                      │
            시리얼 ◀──┤──▶ 영수증 프린터
          (Arduino)
```

```bash
npm run bridge:sim    # 1 — 다리 (버튼·센서 대역이 붙는 길을 연 채로)
npm run wall          # 2 — TouchDesigner 자리 (대역)
npm run sensor        # 3 — HC-SR04 손 감지 자리 (대역). h 가까이 · l 멀리
npm run dev           # 4 — 하늘
```

**장비가 하나도 없어도 전부 돌아간다.** 다리가 꺼져 있어도 체험은 그대로다.

자세한 것은 [`server/README.md`](server/README.md) — 일곱 가지 말, 별이 지나는
다섯 단계, 벽으로 넘어가지 않는 것, TouchDesigner 쪽 붙이는 법.

> 포트는 **9981**이다. 작업본(`~/Desktop/조형실습/AFTERLIGHT/bridge/`)의 다리가
> 9980을 쓰므로 한 칸 옆으로 두었다 — 둘을 함께 띄워도 부딪히지 않는다.
> **그 저장소는 건드리지 않았다.**

> 태블릿을 두 대 놓으면 **지금은 각자 다른 우주를 갖는다.**

## 공동 우주

하나의 우주에 모두의 빛이 쌓인다. 개인용 우주를 따로 만들지 않는다.

### 별 하나가 들고 있는 것

```ts
id            이 빛을 가리키는 이름 (우주 안에서 겹치지 않는다)
seq           전시 통산 번호 — 영수증에 찍힌다
sessionId     익명. 같은 사람이 이어서 보낸 것만 묶는다
source        live | test
text          기억의 한 문장 (80자) ─┐ 시간 기록. 벽으로는 건너가지 않는다
timeRef       그 시간은 언제였나   ─┘
emotion       오늘의 마음 일곱 중 하나
type          keep | letgo          ← 마음과 **나란한 다른 축**
createdAt     보낸 때
arrivedAt     우리의 우주에 닿은 때
x · y         공동 우주에서의 자리
brightness    타고난 밝기
seed          같은 별은 언제나 같은 모습
constellation 어느 별자리에 속하는가 (con-sad …)
status        sending | arrived
```

같은 별이 둘 생기지 않게 세 겹으로 막는다 — store의 빗장(연타),
저장소의 이름 겹침 검사, `markArrived`의 멱등성.

### 별자리는 자란다

- 새 빛은 **자기 마음의 조각 안에서** 이미 있는 빛 곁에 앉는다 (70% 확률)
- 선은 **같은 별자리의 간직한 빛끼리만**, 한 별에 두 개까지
- 엉뚱한 별을 스치는 선, 이미 그어진 선을 가로지르는 선은 긋지 않는다
- **한 번 그어진 선은 지워지지 않는다** — 새 빛이 왔다고 남의 선이 끊기면
  보고 있던 사람에게는 별자리가 제멋대로 다시 그려지는 것으로 보인다
- 조각은 자라지 않고 **안에서 촘촘해진다.** 한 별자리에 대략 100개까지

규칙 자체는 `src/lib/constellationLinks.ts`에 캔버스와 무관한 순수한 셈으로 있다.

### 간직하기 / 흘려보내기

| | 간직하고 싶은 시간 | 흘려보내고 싶은 시간 |
| --- | --- | --- |
| 자리 | 그 자리에 머문다 | 90초에 걸쳐 조금씩 **멀어진다** |
| 빛 | 또렷하게 남는다 | 옅어지되 **0이 되지 않는다** (0.46) |
| 선 | 별자리를 이룬다 | 선을 받지 않는다 |
| 떠난 자리 | — | **잔광이 남는다** |

둘 다 공동 우주의 일부로 남는다. **지우는 길은 두지 않았다.**

### 테스트 데이터

통이 다르다. 한 통에 담고 표만 붙이면 언젠가 지우다가 실제 기록을 함께 지운다.

```
afterlight.universe.v1        실제 관람객의 빛 — 전시의 기록
afterlight.universe.test.v1   점검용으로 만들어 낸 빛
```

- 번호(`seq`)도 따로 센다 — 점검하느라 보낸 스무 개 때문에 첫 관람객이 21번이 되면 안 된다
- `우주 비우기`는 **점검용 통만** 비운다
- 전시 빌드는 점검용 통을 **열지도 않는다**

## 소리

**모든 소리를 Web Audio API로 직접 만든다.** 오디오 파일이 하나도 없다 —
저작권이 걸릴 것도, 받아 올 것도 없다.

| | |
| --- | --- |
| 배경음악 | 느린 패드 4목소리 + 20~34초마다 미끄러지는 화음 + 이따금 떨어지는 유리음. **루프가 없다** — 이어 붙는 자리가 아예 없으므로 경계가 튀지 않는다 |
| 별이 떠날 때 | 마음마다 다른 소리 (아래) |
| 별이 닿을 때 | 미세한 상승음 → 맑은 반짝임 → 짧은 잔향 |
| 글을 쓸 때 | 잡음을 깎아 만든 타자기. 글자마다 음량·길이·깎임이 조금씩 다르다 |
| 누르는 자리 | 짧고 부드러운 넷 — `ui.tap` · `ui.choose` · `ui.back` · `ui.forward` |
| 별을 감상할 때 | 공간이 열리는 소리 · 다가오는 소리 · 시간이 떠오르는 반짝임 |
| 영수증을 펼칠 때 | 얇은 종이가 펴지는 사각거림. 잡음에 **알갱이 포락선** 18개를 씌워 만든다 |
| 잔향 | 임펄스 응답도 직접 만든다 (잡음을 지수로 깎아 4.2초) |

### 일곱 마음의 소리

**같은 소리의 음높이만 바꾸지 않는다.** 여덟 가지가 함께 달라진다 —
음색 · 음높이 · 음의 조합 · 길이 · 어택 · 잔향 · 깎임 · 입자.
어느 두 마음도 **세 가지 이상** 다르다(검증 스크립트가 센다).

```
행복   장3화음 + 9도 · 알갱이 7개 · 가장 넓게 퍼진다
설렘   음이 차례로 올라온다 · 어택이 가장 짧다
평온   5도 하나 · 가장 느리게 올라와 가장 길게 머문다
불안   단2도가 비벼진다 · 떨림(vibrato)이 있는 유일한 소리
무기력 가장 많이 깎여 있다 · 알갱이가 없다
슬픔   단3도가 아래로 · 가장 길게 남는다
기타   꾸미지 않은 한 음
```

`간직하기`와 `흘려보내기`는 **감정의 소리를 덮어쓰지 않는다.**
마음이 소리를 정하고, 이 선택은 **어떻게 끝나는지**만 바꾼다 —
간직은 낮은 바탕음이 받쳐 맺고, 흘려보냄은 꼬리가 길어지며 아래로 흐른다.

소리는 전부 `src/audio/` 한 곳에 있다. 마음별 소리는 `emotionVoices.ts`,
음량과 간격은 `catalogue.ts`에서 고친다.

### 브라우저가 소리를 막을 때

브라우저는 사람의 손짓 전에는 소리를 내지 못하게 막는다. 그래서
**대기 화면을 누르는 그 손짓**에서 깨어난다(전체화면과 같은 자리).
깨어나기 전에 소리를 내려 해도 **아무 일도 일어나지 않는다** — 오류가 나지 않는다.

소리가 꺼져 있어도, 기기에 스피커가 없어도, 화면과 별은 그대로 움직인다.

### 소리 설정

화면 왼쪽 아래 `♪`. 전체 / 배경음악 / 효과음을 따로 켜고 끄며, 음량도 따로다.
고른 것은 이 브라우저에 남는다.

## 확인이 필요한 것

1. **새 프로젝트를 작업본 위에 다시 세울 것인가.** 지금은 공개 저장소를 바탕으로
   짓고, 감정 일곱만 작업본에서 가져왔다. 작업본에는 영수증·별자리 이름 짓기·
   소리·다리까지 있으므로, 그쪽을 바탕으로 삼는 편이 나을 수 있다.
2. **감정의 순서와 '기타'의 자리** — 일곱은 확정된 것으로 보고 그대로 썼다.
   공동 우주에서는 마음이 곧 별자리라 '기타'도 자기 칸을 갖는다. 이대로 두어도 되는지.
3. 키오스크 태블릿의 기종과 OS
4. 영수증 프린터 모델 (58mm / 80mm)
